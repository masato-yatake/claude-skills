# 画面解説スキル（screen-guide）

ユーザーが今見ている Web 画面を、**実物を確認 → HTML/CSSで描き直す → 要素を赤枠で囲み左上に番号 → 番号ごとにカードで解説** の型で1枚のHTMLにする。
用途は「画面を見ながら今すぐ理解する」。納品物ではないので、速さと読みやすさを精度より優先する。

完成例は `assets/example.html`（架空の受注管理アプリ）。初めて使うときは必ず開き、同じ形式で作る。

## なぜこの型か

- 記憶で描くと必ずズレる。だから実物を見てからしか描かない
- スクショに注釈を重ねると画面のノイズ（広告・長文・無関係な列）ごと写る。描き直せば必要な部分だけ残る
- 赤枠で「どこからどこまで」が見え、番号で図とカードを往復できる
- カードの見出しで「状態バッジ ＝ 進み具合」のように意味を言い切るほうが、表より人間が速く読める

実物のスクショに注釈を注入する方式は工程が多いので既定にしない（必要なら `references/precise-mode.md`）。

## 3原則

| 原則 | 意味 |
|---|---|
| 実物優先 | ブラウザで開いた画面（またはユーザーのスクショ）を見てから描く。見ていない画面は描かない |
| 質問しない | 対象＝今開いているタブ、読者＝本人、テーマ＝実物のまま、を既定にして即着手。会話に指定があればそれに従う |
| 完了判定はユーザー | 「完成しました」と言わず、作った内容と未確認点を事実として報告する |

## 動作環境

- **Claude in Chrome が使える**：手順1のとおりタブを開いて確認する
- **使えない**：ユーザーにスクショを頼む（上部・操作対象・下部の3枚が目安）。届くまで描かない。スクショに写っていない部分は描かず「未確認点」に書く

## 手順

### 1. 実物を開く
- `tabs_context_mcp` → タブがなければ `navigate` で同じ Chrome プロフィールに新規タブで開く（ログイン状態は引き継がれる）
- `get_page_text` で文言、`computer` の screenshot で配置・色・テーマを見る。長い画面はスクロールして上部・中部・下部を見る
- 到達経路（URL またはメニュー階層）を控える
- 終わったらタブを閉じる（ユーザーが見たい場合は残す）

### 2. 番号を振る要素を決める
- 読者が「これは何？」と思う要素、押すと何かが起きる要素を選ぶ
- 左上→右下で番号。10を超えるならゾーンに分ける（`references/figure-rules.md`）

### 3. HTMLで描き直す
`assets/guide-template.html` をコピーして埋める。細則は `references/figure-rules.md`。
- テーマ色は実物に合わせて変数を差し替える
- 文言は実物のまま。番号を振らない部分は「…（中略）」で潰す
- **番号だけは不可。要素そのものに `class="f"` を着け、中に `<a class="m" data-t="pN">`**。座標指定のオーバーレイ枠は使わない（幅が変わるとズレる）。カードは `id="pN"`

### 4. カードを書く
1番号＝1カード。where（どこで）／h3（何か＝意味を言い切る）／p（どうなる）。最後に「読む順番の目安」と「未確認点」。

### 5. 出力して報告する
- `<画面名>-guide.html` として保存し、ファイルとして渡す
- 報告は「何画面・何番号」「未確認点」のみ。完了宣言はしない
- 指摘は「番号＋ズレの内容」で受け、該当箇所だけ直す

## やってはいけないこと
- 実物を見ずに描く、文言を言い換える、番号とカードの対応を崩す
- 番号を振らない部分まで律儀に描く
- 赤枠なしで番号だけ置く（範囲が伝わらない）
- 赤枠を `position:absolute` の座標で置く（スマホでズレる）
- 図の外枠に `overflow:hidden` を付ける（左上の番号が切れる。2026-09-07 の実例あり）
- 番号のジャンプに `href="#pN"` を使う（プレビューで外部リンク扱いになり飛べない。テンプレの script を残す）
- 頼まれていないのにスクショ注入方式（精密モード）に切り替える
- 「完成しました」「これで大丈夫です」と締める

## 同梱ファイル
- `assets/guide-template.html`：出力の骨組み（赤枠・双方向ジャンプ・横スクロールを標準装備）
- `assets/example.html`：完成例（架空の受注管理アプリ、1ゾーン6番号）
- `references/figure-rules.md`：描き方・ゾーン・番号・カードの細則
- `references/precise-mode.md`：実スクショに注釈を注入する方式（明示的に頼まれたときだけ）。`annotate.js`・`build_guide.py` はその道具
