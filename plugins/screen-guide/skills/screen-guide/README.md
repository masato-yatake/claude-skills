# screen-guide

Claude 用スキル。ブラウザで見ている Web 画面の「見方・使い方」を、番号付きの図と解説カードで1枚の HTML にまとめます。

## できること
- 画面を HTML/CSS で描き直し、要素を赤枠で囲んで番号を付ける
- 番号ごとに「どこで／それが何か／どうなるか」のカードで解説
- 図の番号 ⇄ カードの番号 を押して往復できる
- 読む順番の目安と、確認できなかった点を末尾に明記

## 使い方
1. claude.ai の設定（Customize > Skills）からこのスキルを追加して ON にする
2. Chrome で解説してほしい画面を開く（Claude in Chrome 拡張があれば Claude が自分で見に行きます。なければスクショを貼ってください）
3. チャットで「この画面の見方を教えて」

質問はせず、その場で HTML を1枚返します。ズレがあれば「番号＋内容」で指摘すると該当箇所だけ直します。

## 動作条件
- claude.ai（Pro 以上）でコード実行・ファイル作成が有効なこと
- Claude in Chrome 拡張は任意。ない場合はスクショ運用

## 注意
- 図は「描き直し」です。実物そのままの見た目が必要な場合は `references/precise-mode.md` の方式を明示的に頼んでください（工程が多く時間がかかります）
- スマホでは図を横にスクロールして見ます（縮めると読めないため）
