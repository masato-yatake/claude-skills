# 精密モード（スクショ注入方式）— 他人に渡すマニュアルを本気で作るときだけ

既定のモック方式で足りないとき（実物の見た目そのものが必要、納品物）に限って使う。工程が5つあり時間がかかるので、ユーザーが明示的に「実物のスクショで」と言ったときだけ。

## 手順
1. `annotate.js` を javascript_tool で読み込む（`sgMark` / `sgClear` / `sgBox` が使える）
2. `sgBox('見出し')` と querySelector で各要素の [x,y,w,h] を集める。固定要素（ヘッダー・左レール・浮きパネル）は分ける
3. `sgMark(page, fixed)` で赤枠＋バッジを注入（バッジは枠の内側左上・44px。外側に置くと画面端で欠ける）
4. `computer` screenshot を `save_to_disk: true` で撮る。固定要素は1枚目だけ番号を付け `sgClear('fixed')` してから下を撮る。保存画像は1568px幅に縮む
5. `build_guide.py plan.json out.html` でゾーン切り出し（1枚に番号3〜5個）・拡大・base64埋め込み

## 環境の制約
- claude.ai：スクショはユーザーのPC（Temp）に保存され手元に来ない。パスを伝えてドラッグしてもらう2ターン運用
- Claude Code（ローカル）：Tempをそのまま読めるが、工程が多く「ついで作業」で時間が膨らみやすい。任せるなら「スキルの手順以外はしない」と明示する
