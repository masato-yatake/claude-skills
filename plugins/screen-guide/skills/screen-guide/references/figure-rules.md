# 図のルール（HTML/CSS で描き直す）

## 描く前に
- 必ず実画面を開いて見る。見ていない画面は描かない
- ダーク／ライトは実物に合わせ、テンプレの `--bg/--panel/--fg/--line` を差し替える
- 文言（ボタン名・タブ名・ラベル・件数）は実物のまま。言い換え・翻訳をしない

## 何を描き、何を省くか
- 描く：番号を振る要素と、その位置関係が分かるだけの周辺（ヘッダー、タブ列、枠線）
- **番号を振らない領域は必ず潰す**。「…（中略）」の点線枠にする。描きたくなっても描かない（読みにくさの主因）
- 実物のレイアウト比率を保つ（2カラムなら2カラム）
- 装飾は不要。枠・文字・色・番号だけで足りる

## ゾーン分割
- 番号が10を超える画面は、縦長1枚にせず**ゾーン**（例：固定要素／左カラム／中央上／中央下）に分けて、ゾーンごとに図＋カードを並べる
- 1ゾーンの番号は3〜6個。番号はゾーン内で連番にする

## 赤枠（必須）
- 番号だけを置かない。**要素そのものに `class="f"` を着け、その中に `<a class="m" data-t="pN">N</a>` を置く**。枠は要素と一緒に動くので、PCでもスマホでもズレない
- 複数の要素をまとめて囲むときは `<div class="f">` で包む
- **座標で枠を置かない**（`position:absolute; left/top/width/height` のオーバーレイは幅が変わるとズレる）。地図上の区画のように要素に紐づかない領域だけ、親を `position:relative` にして % で置く
- 枠同士は重ねない。重なるなら親子どちらかに絞るか、ゾーンを分ける
- 図は `.scroller > .shot`（min-width 760px）に入れ、スマホでは横スクロールにする。縮めると文字が読めない
- `.shot` の padding と `.f` の margin は番号が枠外・隣の枠に食い込まないための余白。テーマ色を差し替えるときも padding を 0 にしない
- **図の中で独自の外枠（ウィンドウ風の div など）を作るとき、`overflow:hidden` を付けない**。番号は要素の左上にはみ出して置く仕様なので、外枠がはみ出しを切り落とし、①や⑩のように端の番号が欠ける。角丸のためでも不要（`border-radius` だけで足りる）。外枠を作るなら左に 12px 程度の padding を入れる

## 番号
- 左上→右下の読み順。行を優先し、同じ行の中では左から右
- 番号マーカーは `<a class="m" data-t="pN">N</a>`。**href="#pN" は使わない**（claude.ai のプレビューでは外部リンク扱いになり飛べない）。テンプレ末尾の script が data-t で scrollIntoView する
- カード側の番号を押すと図の赤枠へ戻る（テンプレ同梱）
- 番号にホバーすると対応する赤枠が光る（`.f:has(>.m:hover)` と `.pre` のフォールバック、テンプレ同梱）。押した後の `.hit` と同じ見た目にして、ホバー＝予告／クリック＝確定と一貫させる
- 同じ要素が複数画面に出るときは同じ番号を使い、カードの where に「画面A・B共通」と書く
- 複数画面を1枚に入れるのは同じ流れ（一覧→詳細→履歴）のときだけ

## 解説カード
- where：読者が1秒で見つけられる位置（「右上の緑」より「タイトル右端の緑『New issue』」）
- h3：「要素名 ＝ 意味」で言い切る（「Closed ＝ 閉じられた issue」）
- p：押す／入れるとどうなるか。読者向けの一言（「まだ押さなくてOK」「取り消せない」）を必要なら添える
- 締めの「読む順番の目安」で最初に見る番号を指示。未確認点は必ず書く
